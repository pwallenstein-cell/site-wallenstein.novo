# Site do Centenário de Carlos Wallenstein (1926–2026)

Site estático (HTML + CSS), publicado com GitHub Pages.

- `index.html`, `biografia.html`, `obra.html`, `arquivo.html`, `sobre.html`, `creditos.html`, `direitos.html`, `contactos.html`: páginas
- `styles2.css`: estilos de todas as páginas
- `assets/`: imagens (capas dos volumes em `assets/capas/`)
- `livros/`: PDFs das Obras Completas (ver `livros/LEIAME.txt`)
